## 五、结论（对外口径，务必照此说）

> 本组交付的是**可运行端到端原型**，不是"银行演示版本"。
> 理由：13.1 的"客服业务"与"稳定性"两项门槛未通过——模型超时/非法 JSON 不降级（T07/T08），C 组隐私与故障案例未按规则处理。
> 已达到的部分：数据边界、MCP 最小权限、跨会话与越权防护、规则发布门禁与回滚、审计可追溯，五项均有实测证据，且关键缺陷 0 起。

## 六、还差什么才能算"银行演示版本"

1. 模型异常降级：超时/非 JSON 时置 status=TIMEOUT/REJECTED 并转人工（坐席端 UI 文案已备，只差后端置位）——需源码
2. C 组隐私判据：备注中出现完整证件号/卡号即告警并阻断复原——需源码
3. 网络级隔离：docker 三网络形态重跑 T12——需 docker-compose 构建
4. 正式盲测：由其他组抽 4 张、独立计时评分——需现场
