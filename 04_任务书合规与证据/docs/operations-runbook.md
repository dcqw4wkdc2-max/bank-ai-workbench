# operations-runbook.md — 运行手册

## 1. 启动
1. 解压客户端到本地磁盘（非只读目录）
2. 双击 `启动.bat`（或 `启动-局域网.bat` 用于手机同网访问）
3. 控制台窗口不可关闭；关闭即停止服务
4. 访问：坐席 http://127.0.0.1:8101/login ｜ 管理同址 `/admin` ｜ 客户 http://127.0.0.1:8103/

## 2. 守护（11-19 新增）
`%TEMP%\bank_watchdog.bat`：每 8 秒检查进程，退出即重启（实测 5 秒内自愈）。
演示前务必先启动看门狗，再启动客户端。

## 4. 常用运维动作
| 目的 | 动作 |
|---|---|
| 重置演示数据 | 关闭程序后删除 `data/` 目录，或双击 `重置演示数据.bat` |
| 换端口 | 启动前设 `INNER_PORT/DMZ_PORT/OUTER_PORT` |
| 故障演练 | `POST :8103/outer/api/v1/_fault {"mode":"timeout"｜"bad_json"｜"ok"}` |
| 看验收数据 | `data/acceptance.json`（看板读它） |
| 看审计 | 管理端「审计追溯」或 `GET /internal/api/v1/audit?request_id=` |
| 备份 | 整个文件夹拷走（含 data 三库） |

## 6. 故障处置
| 症状 | 处置 |
|---|---|
| 页面 502 | 客户端进程挂了 → 看门狗应在 8 秒内拉起；未拉起则双击 `启动.bat` |
| 登录后跳回登录页 | 会话 8 小时到期 → 重登；口令连错 5 次锁 300 秒 |
| 客户提交后一直"AI 应答中" | 上游模型异常，属已知缺陷 T07/T08；刷新页面，或改用坐席端案例演示 |
| 端口被占 | 换 `INNER_PORT` 等三个变量后重启 |
