## 残余风险（必须写进报告）
1. 后端无降级状态机 → 上游异常会静默挂起，演示现场表现为"AI 一直转"。
2. C 组隐私判据缺失 → 带完整证件号的业务请求不会被拦。
3. 单进程形态 → 网络隔离只是逻辑约定。
