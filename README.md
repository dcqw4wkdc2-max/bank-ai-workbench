## 三条规矩

1. `main` 只放能跑的版本；每人开 `feat/名字-做什么` 分支，改完提 PR。
2. 提交信息带编号，例如 `fix: P0-01 客户通道令牌复原`。
3. 不许提交：账号密码表、`.env`、真实客户数据、日志、node_modules。

## 项目硬约束（不要违反）

- 数据不出域：姓名、证件号、卡号、手机号、交易映射只留在内网。
- AI 只给建议，不做最终裁决；疑似未授权、意图不明、规则冲突、超时/非法输出一律转人工。
- MCP 只开白名单工具；每次调用可追到 request_id / 会话 / 规则 / 模型 / 结论。
