# 源码来源与并入步骤

源码不在本仓库里，来自两处：

1. `银行客服AI工作台-源码快照-20261117-精简.zip`（梁晓志 11-17 上传到 WorkBuddy 项目资产）
2. `银行客服AI工作台-v1.5.0-win64.zip`（梁晓志 11-18 15:48 发在组群）

## 并入步骤

```bash
# 1. 解压到本目录
unzip 银行客服AI工作台-源码快照-20261117-精简.zip -d .
# 2. 不要改文件夹名
# 3. 提交
git add . && git commit -m "feat: 源码并入（v1.5.0 快照）" && git push
```

## 并入后必须补三样

1. 启动命令（根目录 README「怎么跑」一节）
2. 环境变量清单（只说需要填什么，不写真实值）
3. 依赖清单（requirements.txt 或 package.json）

> 不要提交：账号密码表、.env、真实客户数据、node_modules。
