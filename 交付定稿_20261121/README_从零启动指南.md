## 二、本机从零跑起来（10 分钟）

**环境要求**：Python 3.10+（建议 3.11）、Git、可访问外网的网络（仅当需要真实模型时）

```bash
cd 01_可运行原型与源码/源码_含补丁

# 1) 建虚拟环境并装依赖
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

pip install -r requirements.txt

# 2) 三区启动（三个独立进程、三个端口、三个库）
python run_local.py
```

启动后：

| 端口 | 区域 | 用途 |
|---|---|---|
| 8103 | 外网 AI 协同域 | 客户体验入口 `http://127.0.0.1:8103/` |
| 8101 | 内网可信域 | 控制台 `http://127.0.0.1:8101/login` |
| 8102 | DMZ 安全交换区 | 只绑回环，不接受浏览器直连（这是边界，不是配置） |

> 三区分进程而不是单进程多路由——单进程里"网络隔离"只是命名。想验证隔离，用 `docker-compose.yml` 起三网络栈（见 `06_部署与维护说明`）。

**模型**：默认 `MODEL_IMPL=real`，读环境变量 `HERMES_BASE_URL / HERMES_API_KEY / HERMES_MODEL`；
未配置或不可达时自动降级为确定性 Mock，**不影响**任何安全行为与测试结论。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 客户页提示「体验会话无效或已过期」 | 会话 2 小时到期 | 回入口页重新点「开始体验」 |
| 控制台一直跳回登录页 | 未登录或会话被同账号顶掉（单会话） | 重新登录；同账号不要两人同时用 |
| `pytest` 全部超时 | 三区未启动 | 先 `python run_local.py`，再跑测试 |
| 页面是旧版本 | 浏览器缓存 | Ctrl+F5；页面已设 `no-store` |
