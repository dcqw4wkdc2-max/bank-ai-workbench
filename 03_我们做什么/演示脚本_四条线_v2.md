# 演示脚本 · 四条线（v2，2026-11-19 12:05 按实测重写）

定位（苏鸿 11/17）：「引出我们的一体机和几个项目组做的案例演示」「放在**安全**板块来介绍」。
所以这不是"我们做了个系统"，是给"AI 安全"这一段当证据：数据不出域、AI 只建议不裁决、全链路可审计。
总时长 2 分 40 秒；讲的人一句交代背景，剩下全是操作。

**v2 改了 3 处**（都是实测推翻的旧台词，别照旧念）：
1. 客户页状态不是"待人工接管"，是"已转人工跟进"；
2. 客户通道对低风险也会转人工 → 客户页只演提交与转人工，给建议走坐席端；
3. 原"线四 故障回退"演示不成立（实测超时会一直悬挂），改成"越权与审计"。

## 线一 · 客户提交（30 秒）

动作：客户入口（手机或浏览器）→ 选"账户" → 输入"账单里有一笔 39.9 元的扣款我不认识，想核对" → 提交。
口播：「客户只做一件事：说清楚发生了什么，拿一个工单号。剩下的都不让客户做。」
看点：工单号 FB2026…、状态"已转人工跟进"。
**注意**：别在这里说"AI 会给它答复"——客户通道目前一律转人工，说错会被追问。

## 线二 · 低风险给出建议（60 秒，全场核心）

动作：坐席端 → 选 A01 → 提交。
口播：「这是低风险争议咨询。注意看发出去的东西——客户姓名变成 NAME_001，卡号 CARD_001，电话 PHONE_001，原始信息一步没出内网。模型回来的是建议不是决定：它引用了 R-DISPUTE-01 和 R-DISPUTE-02 两条规则。」
看点：出域快照 8 个字段（无原值）、令牌化上下文、规则引用、建议摘要 + 动作 REQUEST_DISPUTE_FORM、复原后的完整上下文（内网侧）、采纳回执"已记录：ACCEPT → 工单状态 CONFIRMED"。
若有人要摸键盘：让他自己点一次"采纳建议"，看回执出现。

## 线三 · 高风险强制人工（40 秒）

动作：坐席端 → 选 B01（卡在身边却有 3280 元陌生消费）→ 提交。
口播：「同一套系统，遇到疑似未授权，AI 一个字都不给，直接转人工。不是它不会答，是规则不允许答——R-UNAUTH-01 是强制人工。」
看点：HUMAN_HANDOFF、无复原结果（`restored_text` 为空）、原因码含 MANDATORY_HUMAN。
补一句（有人问就答）：「它有一次还引用了规则库里不存在的规则号，被裁决层挡下来转人工了——我们宁可转人工，不许编。」（真事，B01/B02 的 reason_codes 里有 INVALID_RULE_REFERENCE）

## 线四 · 越权与审计（30 秒）

动作：管理端 → MCP 受控工具 → 选 `execute_sql` 或手输 → 调一次（403）→ 转到审计追溯查这条。
口播：「Agent 想直接查库、想改生产规则，都调不动——白名单里没有这些工具。每次拒绝都留一条审计，带工号、带 trace。」
看点：HTTP 403「策略拒绝」、审计里 MCP_DENIED / not_in_allowlist / high。
可加一句硬证据：「跨会话复原也挡住了：换一个会话 ID 去复原，回 403『会话不匹配』。」

## 收口（20 秒，只讲一句）

「所以银行要的不是更聪明的模型，是**敢让它上生产的那套边界**：数据不出域、AI 不裁决、每一步都能追。这套东西五天做出来，现在能跑，也能被另一个人接手跑。」

## 兜底（必背）

- **被问故障降级**（超时/非法 JSON 怎么办）：老实答——「这块没做完。上游超时会一直挂在那，不会自动转人工，我们把它写在报告的 T07/T08 里了，是这一版最大的缺口。」**不要现场演示这个**，会卡住。
- **被问"这是牛马仕跑的吗"**：老实答——「当前 Agent 编排走 WorkBuddy 托管 Agent，模型走 partner-cloud / 内网 Qwen3.5-9B 端点；牛马仕接入是下一层，任务书按 Mock 先行设计。」
- **被问"代码谁写的"**：「技术核心梁晓志，我负责分工与验收，测试唐丽雯、伍金莲，业务口径唐丽雯。」
