# v1.5.0 客户端验证记录（2026-11-18 22:08—22:25 实测）

验证对象：`银行客服AI工作台-v1.5.0-win64.zip`（37.66 MB，742 个文件）
验证方式：解压到本地 → 双击 `启动.bat` → 浏览器实测三区 → 与网页版逐项对比

## 一、包结构（客观事实）

```
BankAIWorkbench.exe            主程序（PyInstaller 单文件入口）
_internal/                     运行时（numpy / click / websockets / webview 等依赖）
  web/{index,admin,login,password}.html + app.css   前端
  webview/js/{api,customize,finish,state}.js        前端脚本
使用说明.txt / 启动.bat / 启动-局域网.bat / 重置演示数据.bat
```

**不含 Python 源码**：后端为 `.pyd` 编译产物，包内无 `.py`、无 `docker-compose.yml`、无 `requirements.txt`。
前端 HTML/JS 可读，已并入仓库 `02_代码/客户端包可读部分/`（15 个文件）供接手方参考。

## 二、启动与三区（实测）

| 端口 | 区域 | 实测 |
|---|---|---|
| 8101 | 内网可信域 | 200，登录页与管理端正常 |
| 8102 | 安全交换区（DMZ） | `/` 返回 404（网关无根路由，符合预期） |

使用说明原文：「三个区三个独立数据库，跑在同一个进程的不同线程里——演示够用；真实隔离形态见项目内 docker-compose.yml 的三网络拓扑。」

局域网模式：`启动-局域网.bat` 设 `ZONE_HOST=0.0.0.0`，手机同 WiFi 可访问 8103。

## 四、对合规判定的影响

1. **两条 P0 未变**：客户端形态下同样存在，13.1 关键放行条件仍不满足，「不得作为银行演示版本」的判定不变。
2. **T13–T15 具备取证条件**：MCP 工具目录可用，白名单与拒付项都在页面上可见，配合 21:49 已抓到的 `MCP_DENIED / not_in_allowlist` 审计，MCP 权限一项可由「无法取证」改为「阻断可证、白名单可核」。
3. **观测能力增强**：「运行观测」页直接覆盖 13.1 稳定性与运营指标，可作为演示材料。
4. 包形态变化对现场的影响：从「打开链接」变成「解压 + 双击启动」，需提前在演示机上装一次；服务是本地进程，关掉控制台就停。
