# 接口契约 v1.0（冻结 · 2026-11-18）

依据任务书 10.3「Agent 输入输出结构」，结合实测字段冻结。**任何改动须升版本号并同步五组。**

## 1. Agent Input

```json
{
  "request_id": "REQ-20261118-XXXXXX",
  "schema_version": "1.0",
  "trace_id": "REQ-20261118-XXXXXX",
  "intent_hint": "DISPUTE_PROCESS | TRANSACTION_QUERY | UNAUTHORIZED | PENDING_CONFIRM",
  "sanitized_context": "客户 NAME_001 来电，询问卡号 CARD_001 的一笔消费…",
  "approved_rule_context": [{"rule_id": "R-DISPUTE-01", "summary": "…"}],
  "allowed_output": ["intent_summary","reasoning_summary","missing_information","recommended_next_step","risk_flags","source_rule_ids"],
  "issued_at": "2026-11-18T21:40:00+08:00",
  "expires_at": "2026-11-18T21:45:00+08:00",
  "signature": "<sha256-hex>"
}
```

约束：
- `sanitized_context` 中不得出现原值，只允许令牌（`NAME_/CARD_/PHONE_/ID_/AMOUNT_/MERCHANT_` + 3 位序号）
- `expires_at - issued_at = 5 分钟`
- `signature` 覆盖除自身外全部字段
- `allowed_output` 为白名单，模型多输出的字段一律丢弃

## 2. Agent Output

```json
{
  "request_id": "REQ-20261118-XXXXXX",
  "schema_version": "1.0",
  "intent_summary": "…",
  "reasoning_summary": "…",
  "missing_information": [],
  "recommended_next_step": "REQUEST_DISPUTE_FORM | GUIDE_APP_QUERY | COLLECT_MORE_INFO | HUMAN_REVIEW",
  "risk_flags": ["HUMAN_REVIEW_REQUIRED"],
  "source_rule_ids": ["R-DISPUTE-01"]
}
```

约束（任务书 10.3 原文）：输出中不得包含真实客户字段、恢复后的姓名/卡号、执行动作状态或未经批准的政策承诺；内网必须重新验证规则引用与风险标记。

## 4. 审计事件契约（三区）

内网：`TOKENIZED` `ADJUDICATED` `RESTORED` `HUMAN_CONFIRMED` `FB_INGESTED` `FB_AI_REPLIED` `FB_AI_FORCED_HUMAN` `AUTHZ_DENIED` `LOGIN_OK` `LOGOUT`
DMZ：`FB_INBOUND` `FB_STATUS_RELAYED` `FB_OUTBOUND_DELIVERED` `MCP_DENIED`
外网：`FB_TICKET_RECEIVED` `FB_REPLY_CACHED`
必备字段：`事件名 / 区域 / request_id 或会话 / 级别 / 详情(JSON) / 时间(ISO8601+08:00)`

## 5. 错误码

| 场景 | 形态 |
|---|---|
| 路由不存在 | `{"detail":"Not Found"}` |
| 未登记工具 | `{"status":403,"response":{"detail":"策略拒绝：未登记"}}` |
| 门户不匹配 | `AUTHZ_DENIED portal_mismatch`（审计） |
| 反馈超长 | `提交失败：反馈内容须为 1-500 字` |
| 反馈为空 | `请填写反馈内容` |
| 账号越权 | `该账号无权登录此入口` |

## 6. 变更规则

1. 改字段 = 升 `schema_version`，并在本文件追加变更记录。
2. 五组共用同一契约，任何一组改字段须先在此登记，否则视为不合规实现。
