| B2 局域网（手机看） | 现场用手机给客户看 | 双击 `启动-局域网.bat`（`ZONE_HOST=0.0.0.0`），手机同 WiFi 访问 `http://<电脑IP>:8103/` | ✅ 可用（需放行防火墙） |
| B3 服务器自托管 | 不依赖笔记本的对外演示 | 服务器 docker + wine 11 跑 exe，数据卷 `bankdemo_data`、wine 前缀卷 `bankdemo_wine`；Nginx 19092→18103 / 19093→18101（Basic Auth） | ✅ 已上线（43.138.192.118:19092） |

### B3 的完整启动命令（服务器上）
```bash
sudo docker run -d --name bankdemo --restart unless-stopped \
  -e TZ=Asia/Shanghai -e ZONE_HOST=0.0.0.0 -e MODEL_IMPL=real \
  -p 127.0.0.1:18101:8101 -p 127.0.0.1:18102:8102 -p 127.0.0.1:18103:8103 \
  -v /opt/bankdemo:/app:ro -v bankdemo_data:/app/data -v bankdemo_wine:/root/.wine \
  --entrypoint bash scottyhardy/docker-wine -lc \
  'wine reg add "HKLM\System\CurrentControlSet\Control\TimeZoneInformation" /v TimeZoneKeyName /d "China Standard Time" /f >/dev/null 2>&1; \
   mkdir -p /app/data/logs && chown -R $(id -u):$(id -g) /app/data && exec wine /app/BankAIWorkbench.exe'
```
注意三条实测坑：① 容器内必须 `ZONE_HOST=0.0.0.0`，否则 `-p` 映射不到；② `/app` 只读挂载 + 单独挂 `/app/data` 可写卷，否则写日志报 `PermissionError`；③ wine 的时区按注册表走，`TZ` 环境变量对它无效（所以页面时间仍需前端 `fmtTs()` 转本地）。
