# 接口说明（实测反推版 · 2026-11-18）

> 本文不是源码导出的接口文档，是我在浏览器里跑真实流程 + 读三区审计记录反推出来的契约。
> 字段名、动作码、事件名都是**实测到值**；标注「待核」的地方需要源码确认。

## 一、入口与服务

| 用途 | 路径 | 鉴权 |
|---|---|---|
| 客户入口 | `/` | 无（sharecode 不是访问控制） |
| 统一登录 | `/login?sharecode=<code>` | 工号+口令 |
| 坐席端 | `/client` | 坐席角色（B 系列工号） |
| 管理端 | `/admin` | 管理角色（A 系列工号） |
| 员工入口页 | `/staff` | **已废弃，返回 `{"detail":"Not Found"}`** |

账号体系：`A001 管理员 / T001 开发 / B001—B004 坐席`；无公开注册，只能管理员发放；连续 5 次错口令锁 300 秒。

## 二、案例处理（坐席端主流程）

请求（UI 触发）：选案例 → `提交并处理`
响应体结构（实测原样字段）：

```json
{
  "request_id": "REQ-20261117-527AD4",
  "schema_version": "1.0",
  "trace_id": "REQ-20261117-527AD4",
  "intent_hint": "DISPUTE_PROCESS",
  "sanitized_context": "客户 NAME_001 来电，询问如何对卡号 CARD_001 的一笔消费发起争议…",
  "approved_rule_context": [{"rule_id": "R-DISPUTE-01", "summary": "…"}],
  "allowed_output": ["intent_summary","reasoning_summary","missing_information","recommended_next_step","risk_flags","source_rule_ids"],
```

要点：草稿包 5 分钟过期；带签名；出域前完成令牌化；`allowed_output` 是白名单，模型只能填这几个字段。

## 三、动作码（实测出现过的全集）

| 动作码 | 含义 | 出现场景 |
|---|---|---|
| `SHOW_SUGGESTION` | 给出建议，交人工确认 | A01/A02/A04 低风险 |
| `REQUEST_DISPUTE_FORM` | 引导客户走争议申请 | 争议咨询 |
| `GUIDE_APP_QUERY` | 引导 App 自助查询 | 交易查询 |
| `COLLECT_MORE_INFO` | 信息不足，补充后再判 | B03 意图不明、B04 规则冲突 |
| `HUMAN_REVIEW` | 转人工核查 | B02 疑似未授权 |
| `HUMAN_HANDOFF` | 强制转人工（决策值） | B01/B02/B03/B04 |

## 四、状态值（实测）

`AI_ANSWERING`（客户侧应答中）｜`AI_ANSWERED`/`AI 已回复`｜`HUMAN_HANDOFF`/`待人工接管`｜`RESTORED`｜`CONFIRMED`｜`FAILED`（故障演练预期值，当前未实现）

已知问题：状态与决策是两个字段，会出现「状态 HUMAN_HANDOFF、决策 SHOW_SUGGESTION」的冲突（P1-02）。

## 五、审计事件（三区，实测名称）

- 内网：`FB_INGESTED`、`FB_AI_REPLIED`、`FB_AI_FORCED_HUMAN`、`TOKENIZED`、`ADJUDICATED`、`RESTORED`、`HUMAN_CONFIRMED`、`LOGIN_OK`、`LOGOUT`、`ZONE_START`
- DMZ：`FB_INBOUND`、`FB_STATUS_RELAYED`、`FB_OUTBOUND_DELIVERED`
- 外网：`FB_TICKET_RECEIVED`、`FB_REPLY_CACHED`

事件载荷示例（实测）：`ADJUDICATED` 带 `decision / model / agent_version / conflicts / reasons`；`TOKENIZED` 带 `counts / tokens`；`RESTORED` 带 `fields`。

## 六、令牌规则

前缀 + 三位序号：`NAME_001`、`CARD_001`、`PHONE_001`、`ID_001`、`AMOUNT_001`、`MERCHANT_001`。
复原须三元匹配（request_id + session + 令牌表）；**当前客户通道未执行复原**（P0-01）。

## 七、错误码与文案（实测）

| 场景 | 返回 |
|---|---|
| 路由不存在（/staff） | `{"detail":"Not Found"}` |
| 反馈超长 | `提交失败：反馈内容须为 1-500 字` |
| 反馈为空 | `请填写反馈内容` |
| 账号越权登录 | `该账号无权登录此入口` |
