| 入口 | 地址 | 说明 |

| 客户演示 | http://43.138.192.118:19092/ | 公开访问，无需登录（只放合成数据） |
| 内部/坐席与管理 | http://43.138.192.118:19093/ | HTTP Basic 口令：`demo / WgBank2026`（上线后建议改） |

坐席账号 `b001 / abc122333`，管理账号 `a001 / abc123456`（口令见《账号密码表》）。

## 二、它是怎么跑起来的（重要，决定了可用性）

```
客户浏览器
   → 腾讯云 43.138.192.118:19092（Nginx）
      → 127.0.0.1:19090（SSH 反向隧道）
         → 演示电脑 127.0.0.1:8103（客户端包里的外网区）
      （19093 同理，映射到 8101 内网区，带口令）
```

**硬依赖：演示用那台 Windows 电脑必须开机、联网、客户端与隧道进程都在跑。**
任一环节断掉，外网就访问不了；这台电脑关机 = 服务下线。

已做的加固：
- Nginx 只新增 `bankdemo.conf` 与口令文件，未改动服务器上任何现有站点
- 控制台走 Basic Auth；客户页保持公开（内容全部合成，无真实客户信息）
- 隧道带自动重连（掉线 10 秒重试）

## 三、怎么启停

启动（演示电脑上）：
1. 双击客户端 `启动.bat`（黑色控制台不要关）
2. 双击 `%TEMP%\bank_demo_tunnel.bat`（隧道，掉线自动重连）

关闭：关掉上面两个窗口即可；服务器侧 Nginx 保持不动（访问会 502）。

## 四、现场四段（2 分 40 秒）

1. 客户入口提交一条反馈 → 出 `FB` 工单号
2. 坐席端选 `A01` → 提交并处理 → 建议摘要 / 建议动作 / 规则引用
3. 选 `B01` → 强制转人工，客户侧只说「已转人工跟进」
4. 管理端 → 审计追溯 → 按 request_id 查到上面两条
